# dw-schemas

跨 app / package 共享的 Pydantic 契约层，**只定义「形状」，不定义行为**。

职责边界：这里是数据流经各层时的公共语言（错误信封、健康检查模型…）。
任何 IO、任何框架细节都不允许出现在本包中 —— 那属于 `dw-infrastructure`。

| 模块 | 内容 | 对应需求 |
|------|------|----------|
| `envelope.py` | 统一错误信封、错误码分类（`ErrorCode` → HTTP 状态 / 是否可重试） | §25 错误处理 |
| `health.py` | 组件健康模型、系统状态聚合规则 | §31 质量门控（健康检查） |
